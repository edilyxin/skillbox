# 机器档案模板（每台机器一份，权威副本放用户级 MEMORY.md）

> 使用方法：为每台维护过的机器复制本模板并填写，粘贴到该机用户级 MEMORY.md
> （`C:\Users\<用户>\.workbuddy\user-<uuid>-personal\MEMORY.md`）。
> 档案是"活"的：每次维护后更新指标基线与整改历史。敏感信息（密码/API key 明文）不写入。
