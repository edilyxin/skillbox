# computer-maintenance — 电脑维护类技能

收录"把一台电脑调到最优状态并长期维持"的方法论技能。

## 收录标准

- 面向"机器"而非"某项软件功能"：体检、优化、清理、建档、持续维护
- 可跨机器复用：只含方法论 + 模板，不含任何单台机器的私有数据

## 收录技能

| 技能 | 可用系统 | 当前版本 | 状态 | 说明 |
|---|---|---|---|---|
| pc-maintenance | Windows | 1.0.0 | ✅ 活跃 | 体检→整改→验证→建档→持续维护全闭环，四大支柱 |
